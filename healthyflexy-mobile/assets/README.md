# assets

Поточні зображення в `images/` — **плейсхолдери** (зелена іконка з галочкою). Замініть на фірмові перед публікацією:

| Файл | Розмір | Примітка |
|---|---|---|
| `images/icon.png` | 1024×1024, без прозорості | іконка iOS/Android |
| `images/adaptive-icon.png` | 1024×1024, прозорий фон | foreground для Android adaptive icon (значущий вміст у центральних 66%) |
| `images/splash-icon.png` | 1024×1024, прозорий фон | на кольоровому тлі `#1F9D6B` |
| `images/notification-icon.png` | 96×96, лише біла silhouette на прозорому | Android push-іконка |
| `images/favicon.png` | 48×48 | web (не використовується у v1) |

- `demo/` — резервні демо-відео вправ (основні джерела — URL із `exercises.demo_video_url`).
- `fonts/` — власні шрифти (якщо будуть; поки використовуємо системні).
