# SMS: вхід за номером телефону (SMSAPI.com)

Вхід за телефоном: номер → SMS із випадковим 6-значним кодом → код. Правила ті самі, що й для пошти:
код діє 5 хвилин, одноразовий, повтор через 60 с, після 5 помилок анулюється; SMS лише на країни з `SMS_ALLOWED_COUNTRIES` (PL, UA).

## Чому SMSAPI.com

Порівняння цін за одне SMS (жовтень 2026, сайти провайдерів):

| Провайдер | Польща | Україна | Примітка |
|---|---|---|---|
| **SMSAPI.com** | **€0.036** (усі оператори) | **€0.146** | польська компанія (ЄС, GDPR), без абонплати, безкоштовні тестові SMS, мінімальне поповнення €30 |
| Plivo | $0.0285–0.068 (залежить від оператора) | $0.166 | |
| Twilio | $0.0457 | дорожче | лишився запасним (`SMS_PROVIDER=twilio`) |

Орієнтовно: 1000 входів у Польщі ≈ €36, в Україні ≈ €146. Код приходить лише при вході/реєстрації (сесія живе 30 днів).

## Підключення (≈10 хвилин)

1. smsapi.com → **Register** (бізнес-акаунт), підтвердіть пошту й телефон, поповніть баланс (від €30).
2. **Settings → API tokens (OAuth) → Generate token**, право **SMS**. Скопіюйте токен.
3. (Рекомендовано) **Sender names → Add**: ім'я до 11 латинських символів, напр. `Turbota`. Після підтвердження SMS приходять від цього імені.
   Поки ім'я не підтверджене — залиште `SMSAPI_SENDER` порожнім (буде ім'я за замовчуванням акаунта).
4. Railway → змінні бекенду:

```
SMS_PROVIDER=smsapi
SMSAPI_TOKEN=<токен>
SMSAPI_SENDER=Turbota
# акаунт на smsapi.pl (а не .com) → SMSAPI_URL=https://api.smsapi.pl
```

5. Перезапуск. Лог старту: `✅ SMS: SMSAPI (...)`. У застосунку вкладка «Телефон» → свій номер → SMS із кодом.

## Що бачите

| Де | Значення |
|---|---|
| лог `event:sms_accepted provider:smsapi sid:...` | SMSAPI прийняв SMS (id видно в SMSAPI → Messages) |
| лог `event:sms_failed ... hint:...` | відмова; `hint` — що виправити (токен, баланс, ім'я відправника, номер) |
| лог старту `❌ SMS_PROVIDER=smsapi, але немає SMSAPI_TOKEN` | не задано токен |
| застосунок: «Вхід за номером телефону поки недоступний…» | у production SMS-сервіс не підключено (`GET /auth/config → phoneEnabled: false`); вкладка «Пошта» працює |

Локально: `SMS_PROVIDER=console` — SMS не надсилається, текст із кодом друкується в лозі сервера.
