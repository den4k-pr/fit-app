# Книжка турботи · CRM

Панель керування мобільним застосунком: користувачі та їхня статистика, каталог вправ, готові програми
(базовий пакет), ліміти вправ, палітра кольорів і тексти екранів (онбординг). Зміни палітри й текстів
застосунок підтягує з сервера під час запуску — нову версію випускати не треба.

## Запуск локально

```bash
npm install
cp .env.example .env        # VITE_API_URL — адреса API бекенду з /api/v1
npm run dev                 # http://localhost:5174
```

На бекенді мають бути задані `ADMIN_EMAIL`, `ADMIN_PASSWORD` і `ADMIN_CORS_ORIGINS`
(адреса цього сайту, напр. `http://localhost:5174`). Інакше вхід поверне помилку.

## Деплой

Збірка — статичний сайт: `npm run build` → папка `dist/`.

- **Railway**: новий сервіс із цієї папки; змінна `VITE_API_URL`; команда запуску — `npm start` (роздає `dist`, SPA-маршрути працюють).
- **Vercel / Netlify**: build `npm run build`, output `dist` (правила SPA вже є: `vercel.json`, `public/_redirects`).

Після деплою додайте адресу сайту в `ADMIN_CORS_ORIGINS` бекенду.

## Тексти застосунку

Стандартні тексти екранів беруться з перекладів мобільного застосунку. Якщо ви змінили переклади
в `healthyflexy-mobile/src/i18n/locales`, оновіть копію: `npm run sync-texts`.
